# 内网部署指南

本指南适用于在内网环境中构建 IntelliBridge Docker 镜像。

## 方案优势

- ✅ **无需 apt 源**：不在容器内安装 xz-utils，适合无 apt 源的内网环境
- ✅ **传输量小**：只需传输代码和 Node.js 压缩包（~31MB + 代码）
- ✅ **构建快速**：使用预解压的 Node.js，无需在容器内解压
- ✅ **灵活配置**：支持自定义内网 PyPI 和 NPM 镜像源

## 前置准备

### 1. 下载 Node.js 二进制包

在有外网访问的机器上，从阿里云镜像下载 Node.js 24：

```bash
# 创建 build 目录
mkdir -p build

# 下载 Node.js 24.1.0
curl -L -o build/node-v24.1.0-linux-x64.tar.xz \
  https://mirrors.aliyun.com/nodejs-release/v24.1.0/node-v24.1.0-linux-x64.tar.xz
```

其他下载源（备用）：
- 清华镜像：https://mirrors.tuna.tsinghua.edu.cn/nodejs-release/
- 淘宝镜像：https://npmmirror.com/mirrors/node/

### 2. 配置内网镜像源

复制配置文件模板：

```bash
cp .build.env.example .build.env
```

编辑 `.build.env` 文件，修改为内网镜像源地址：

```bash
# Python 镜像源（修改为内网 PyPI 地址）
PYTHON_PIP_INDEX_URL=http://内网-pypi-地址/simple

# NPM 镜像源（修改为内网 npm 地址）
NPM_REGISTRY=http://内网-npm-地址

# Node.js 版本（通常不需要修改）
NODE_VERSION=24.1.0
NODEJS_DISTFILE=node-v24.1.0-linux-x64.tar.xz
```

### 3. 准备部署包

将以下文件打包传输到内网服务器：

```bash
# 必需文件
- build.sh           # 构建脚本
- Dockerfile
- requirements.txt
- .build.env         # 配置好的环境变量
- build/node-v24.1.0-linux-x64.tar.xz
- config/config.yaml
- tools/             # 工具目录
- utils/             # 工具类目录
- main.py
```

使用以下命令打包：

```bash
tar -czf intellibridge-deploy.tar.gz \
  build.sh \
  Dockerfile \
  requirements.txt \
  .build.env \
  build/node-v24.1.0-linux-x64.tar.xz \
  config/ \
  tools/ \
  utils/ \
  main.py
```

## 内网构建

### 方法一：使用构建脚本（推荐）

在内网服务器上解压并执行构建脚本：

```bash
# 解压部署包
tar -xzf intellibridge-deploy.tar.gz
cd intellibridge

# 确保构建脚本有执行权限
chmod +x build.sh

# 执行构建（自动解压 Node.js 并构建镜像）
./build.sh
```

构建脚本会自动：
1. 检查 `.build.env` 配置
2. 验证 Node.js 压缩包
3. 解压 Node.js 到 `build/node-v24.1.0-linux-x64/`
4. 使用配置的镜像源构建 Docker 镜像
5. 验证镜像是否正常
6. 清理临时文件

### 方法二：手动构建

```bash
# 解压部署包
tar -xzf intellibridge-deploy.tar.gz
cd intellibridge

# 1. 加载环境变量
export $(cat .build.env | grep -v '^#' | xargs)

# 2. 解压 Node.js
mkdir -p build/node-v24.1.0-linux-x64
tar -xf build/node-v24.1.0-linux-x64.tar.xz -C build/

# 3. 构建镜像
docker build \
  --build-arg PYTHON_PIP_INDEX_URL=${PYTHON_PIP_INDEX_URL} \
  --build-arg NPM_REGISTRY=${NPM_REGISTRY} \
  --build-arg NODE_VERSION=${NODE_VERSION} \
  -t intellibridge:latest .

# 4. 清理临时文件（可选）
rm -rf build/node-v24.1.0-linux-x64
```

## 验证构建

```bash
# 验证 Node.js 版本
docker run --rm intellibridge:latest node --version
# 预期输出: v24.1.0

# 验证 npm 版本
docker run --rm intellibridge:latest npm --version
# 预期输出: 11.x.x

# 验证 agent-browser
docker run --rm intellibridge:latest agent-browser --version
# 预期输出: agent-browser 0.17.1

# 验证 Python 依赖
docker run --rm intellibridge:latest python -c "import fastapi; import fastmcp; print('OK')"
# 预期输出: OK
```

- **基础镜像**: python:3.12-slim
- **Node.js 版本**: 24.1.0
- **agent-browser 版本**: 0.17.1
- **镜像大小**: 约 **291 MB**

## 导出和传输镜像

如果需要将构建好的镜像传输到其他服务器：

```bash
# 导出镜像（压缩）
docker save intellibridge:latest | gzip > intellibridge.tar.gz

# 在目标服务器上导入
gunzip -c intellibridge.tar.gz | docker load
```

## 常见问题

### Q: 构建脚本提示 "未找到 .build.env 文件"？

A: 请先复制配置模板：
```bash
cp .build.env.example .build.env
# 然后编辑 .build.env 配置内网镜像源
```

### Q: 构建脚本提示 "未找到 Node.js 压缩包"？

A: 请先下载 Node.js 二进制包到 build/ 目录：
```bash
mkdir -p build
curl -L -o build/node-v24.1.0-linux-x64.tar.xz \
  https://mirrors.aliyun.com/nodejs-release/v24.1.0/node-v24.1.0-linux-x64.tar.xz
```

### Q: 如何更换 Node.js 版本？

A: 编辑 `.build.env` 文件，修改 `NODE_VERSION` 和 `NODEJS_DISTFILE`，然后重新下载对应的压缩包。

### Q: 内网没有 npm 镜像怎么办？

A: 可以在有外网的机器上预下载 agent-browser：
```bash
mkdir -p build/npm-packages
npm pack agent-browser --pack-destination build/npm-packages
# 然后修改 Dockerfile，使用本地 tgz 文件安装
```

### Q: Docker 构建时提示 "Cannot connect to the Docker daemon"？

A: 请确保 Docker 服务正在运行，并且当前用户有 Docker 权限：
```bash
sudo systemctl start docker
sudo usermod -aG docker $USER
# 重新登录后生效
```

### Q: 如何自定义镜像标签？

A: 在执行构建时设置 `IMAGE_TAG` 环境变量：
```bash
IMAGE_TAG=intellibridge:v1.0.0 ./build.sh
```
